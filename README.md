# 18 - 2048 スライディング タイル

**slug**: 2048-sliding-tiles
**category**: fun/game
**build-date**: 2026-11-02

## 概要

クラシックな 2048 スライディングパズルゲーム。4×4グリッドで同じ数字のタイルを合体させ 2048 を目指す。

## 機能

- 矢印キー操作
- スワイプ（タッチ）操作対応
- スコア・ベストスコア（localStorage）
- タイル値に応じた色分け（2〜2048）
- 勝利（2048到達）・ゲームオーバー検出
- CSS トランジションアニメーション

## 技術仕様

- 純粋な DOM 操作（Canvas 不使用）
- localStorage でベストスコア保存
- タッチイベントでスワイプ検出
